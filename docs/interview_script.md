# ReplyFlow 面试演示脚本（约 5–7 分钟）

## 开场：定位与边界（30 秒）

> ReplyFlow 是一个搭载在电商邮件系统顶部聚合站内信上的 AI 回复 Agent 原型。它不替代原邮件工作台，也不连接真实 Amazon、邮箱或支付接口。我的重点是验证：邮件进入后，Agent 如何结合订单事实、风险分级和人工确认完成可追溯的回复处理。

强调：页面中的邮件、订单、发送和 ROI 都是虚构或本地模拟；Coze 只负责分析和草稿生成，本地代码负责事实、风险、状态、确认、幂等和审计。

## 1. 一级物流咨询：动态接入与自动处理（约 90 秒）

1. 打开 `http://localhost:8506/`，确认页面先是原客服邮件工作台形态，智能客服处于关闭状态。
2. 点击右下角「模拟邮件台」。
3. 选择虚构订单 `ORD-1001`，输入：`Hi, where is my order? The tracking page has not changed since yesterday.`
4. 提交后说明：邮件先进入原始收件箱，再聚合到顶部站内信；这是动态数据流，不是静态截图。
5. 打开智能客服开关，观察 Coze 分析、订单/物流 Tool 查询、风险网关和回复状态。
6. 如果该案例被判为 L1，展示「AI 自动回复」和本地模拟发件箱；如果环境额度不足导致失败，展示失败提示和「重试 AI」，不要切换到本地规则冒充成功。

面试表达：低风险自动化的前提不是“模型说可以”，而是本地风险网关和事实查询都通过。

## 2. 二级尺码/换货咨询：草稿、编辑和确认（约 60 秒）

1. 再次打开模拟邮件台，输入：`The jacket is too small. Can I exchange it for one size up?`，可关联 `ORD-1002`。
2. 开启智能客服，等待生成 L2 草稿。
3. 展示草稿进入原有回复输入框，点击「AI回复并模拟发送」。
4. 先编辑一句措辞，再点击发送；说明发送只写入本地 outbox，并记录确认和 operation_id。

面试表达：L2 的 Agent 目标是减少撰写成本，但保留店管最后确认权。

## 3. 三级退款/拒付：高风险提示与阻断（约 90 秒）

1. 输入：`I want a full refund now. If you do not refund me today, I will file a chargeback.`，可关联 `ORD-1003`。
2. 开启智能客服，展示 L3 草稿、风险原因和「AI生成，需要人工核对」提示。
3. 不勾选核对清单，点击发送，展示按钮被阻断或返回 `CHECKLIST_REQUIRED`。
4. 勾选“已核对订单与物流事实”“已检查事实和承诺”“仅写入本地模拟发件箱”，再发送，展示成功写入 outbox。

面试表达：高风险邮件不允许模型直接承诺退款、赔付或法律结论；Agent 只生成参考草稿，安全门槛由本地控制层执行。

## 4. 可追溯性、幂等和失败重试（约 45 秒）

- 展开「风险与处理依据」，展示风险决策、Tool Trace 和审计信息。
- 对同一会话重复点击发送，说明 `operation_id` 防止重复写入 outbox。
- 模拟 Coze 失败时，页面只提示 AI 处理失败；点击「重试 AI」重新发起任务，不伪造草稿、不重复接入邮件。

## 5. 评测与 ROI（约 60 秒）

1. 打开 `evals/reports/eval_demo.md`，说明 30 条案例、13 条 R2 高风险案例。
2. 诚实展示 Demo 结果：高风险召回 61.5%，未授权承诺违规 0，无依据订单事实违规 0，控制验证全部通过；因此自动决策为 No-Go。
3. 说明 Interactive 因 Coze 工作区额度不足记录为 No-Go，没有伪造模型结果。
4. 展开页面底部 ROI 面板，切换保守/基准/乐观并调整 L3 占比；强调这是敏感性分析，不是公司真实收益承诺。

## 6. 架构收尾（约 45 秒）

> 我没有把所有逻辑都放进 Coze，也没有一开始就做完整后端。Coze 适合模型编排，代码层适合确定性事实、风险、状态、幂等和审计；混合架构既能快速验证 Agent，又能把高风险控制留在可测试、可回放的边界内。

最后打开 `docs/replyflow_case_study.html` 或 PDF，展示项目定位、方案取舍和限制。

## 演示兜底

- Coze 不可用：使用已保存的 Demo 评测报告和本地页面状态，明确说明模型调用失败，不声称 Interactive 成功。
- 网络不稳定：优先演示已写入本地的 L2/L3 会话和控制阻断，再展示动态模拟邮件浮窗。
- 不展示 `.env`、PAT、真实姓名、真实店铺、真实邮箱或任何外部接口凭证。
