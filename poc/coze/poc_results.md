| P01 首次超时 | Coze 单次工作流执行超过本地 30 秒超时阈值 | 保留失败记录；重试后成功。正式 UI 需显示“模型超时，切换 Demo Mode/重试” |

## 4. 阶段结论

- Coze Analyze/Draft 的请求、响应和 Run ID 已完成真实验证。
- 7 条案例达到 6/6 或 5/5；P01、P06 在修正/重试后通过；P05 的依据越界表述已被本地风险网关识别并拦截。
- Coze 只负责分析和草拟；事实查询、风险分级、确认门槛和模拟发送仍由本地控制层负责。
- 当前不能声称“8 条 POC 全部无缺陷通过”，因为 P05 暴露了模型输出质量问题；但本地控制层已能识别并阻断该问题，可以进入 Interactive UI 开发。
